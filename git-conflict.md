# Конфликт в Git

## Где
Файл `README.md`, строка `**Статус:**`.

## Почему
Две ветки изменили одну и ту же строку по-разному:

- `feature/ui` → `**Статус:** можно добавить идею и увидеть список` (уже была слита в `main`)
- `docs/readme` → `**Статус:** документация готова, код в разработке`

Общий предок — коммит `0b27127` «Добавить план API: 4 эндпоинта», где строка была `**Статус:** в разработке`.

При `git merge --no-ff docs/readme` в `main` git не смог выбрать вариант:

```
КОНФЛИКТ (содержимое): Конфликт слияния в README.md
Сбой автоматического слияния; исправьте конфликты, затем зафиксируйте результат.
```

## Как выглядел конфликт

```
<<<<<<< HEAD
**Статус:** можно добавить идею и увидеть список
=======
**Статус:** документация готова, код в разработке
>>>>>>> docs/readme
```

## Как решён
Вручную. Оба варианта устарели — к моменту слияния приложение было готово целиком.
Маркеры удалены, оставлена итоговая строка:

```
**Статус:** готово — добавление идей, список, кнопки «Реализовано» и «Отклонить»
```

Раздел «Запуск» из `docs/readme` влился автоматически — он в других строках.

## Коммит с исправлением
`784ea22` — «Разрешить конфликт в README: объединить строку статуса» (merge-коммит с двумя родителями: `426f12e` из `main` и `1f9cb6d` из `docs/readme`).
