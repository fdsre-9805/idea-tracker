# Заметки по проекту — Журнал идей

## Цель
Не терять идеи и видеть, какие из них реализованы, а какие осознанно отброшены.

## Пользовательский сценарий
1. Открыть страницу.
2. Написать идею, нажать «Добавить» — идея сохраняется в БД.
3. У идеи две кнопки:
   - «Реализовано» — идея сделана;
   - «Отклонить» — идея отброшена.
4. Закрытые идеи остаются в списке серым.

## Статусы
- New — новая, открытая
- Implemented — реализована
- Rejected — отклонена

Менять статус можно только у новой идеи.

## Решения
- **PostgreSQL 16** — с КТ «Compose» (2026-10-18) вместо SQLite: база запускается отдельным сервисом `db` в Docker Compose. До этого был SQLite — одна БД-файл без отдельного сервера.
- **Веб, а не десктоп** — легко запускать на Linux и упаковать в Docker.
- **Без удаления** — отклонённая идея тоже результат.

## Развитие по курсу
- Linux: запуск как systemd-сервис
- Docker: Dockerfile, БД в volume
- Docker Compose: приложение + PostgreSQL
- Архитектура: слои API / сервис / репозиторий
- Финал: теги, поиск, авторизация
